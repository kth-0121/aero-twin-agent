## 전체 흐름

```
┌──────────────────────────────┐
│ Experimental Dataset         │
│   316L, 677 tracks           │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ Data Preparation             │
│   x = Process State + derived│
│   y = Observed State (W,R,A) │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐   y_hat_k   ┌───────────────────┐
│ Looped Transformer           ├────────────▶│ Physics Evaluator │
│   (ML Predictor)             │◀────────────┤   (Rosenthal ...) │

               │                  (k = 1..3)
       ┌───────┴──────────┐
       ▼                  ▼
┌──────────────┐  ┌──────────────────┐

└──────────────┘  └──────────────────┘
```

              ┌──────────────┴────────────────┐

│   d_laser   [mm]          │   │   melt_area   A [um^2]   │
│   t_powder  [um]          │   │   balling     [0/1]      │
└─────────────┬─────────────┘   └────────────┬─────────────┘
              ▼                              ▼
┌───────────────────────────┐   ┌──────────────────────────┐
│ + Derived features        │   │ Target y                 │
│   linear_energy       E_L │   │   W                      │
│   peclet_number       Pe  │   │   R = D / W              │
│   normalized_enthalpy H*  │   │   A                      │
│ = x (7 features)          │   │   (balling: not used)    │
└─────────────┬─────────────┘   └────────────┬─────────────┘
              └──────────────┬───────────────┘
                             ▼
┌──────────────────────────────────────────────────────────┐

│ fit_scalers      StandardScaler (fit on train only)      │
└──────────────┬───────────────────────────────┬───────────┘
               │ x (7, scaled)                 │ y (3, scaled)
               ▼                               │
   ┌───────────────────────────────────┐       │
┌─▶│ tokens = [Tokenizer(x) | s_k]     │       │
│  └────────────────┬──────────────────┘       │
│                   ▼                          │
│  ┌───────────────────────────────────┐       │
│  │ TransformerEncoder                │       │

│  └────────────────┬──────────────────┘       │
│                   ▼                          │
│  ┌───────────────────────────────────┐       │
│  │ state_head -> y_hat_k = [W, R, A] ├──┐    │
│  └────────────────┬──────────────────┘  │    │
│                   ▼                     │    │
│  ┌───────────────────────────────────┐  │    │

│  └────────────────┬──────────────────┘  │    │

               │     (alpha = 0 by default)               │
               └──────────────────────────────────────────┘

Inference : y_hat_3 -> inverse_transform -> W, D = W * R, A
