## Digital Twin

folder: backend - 실제 서비스 구동에 필요한 fastapi기반의 서버입니다.
folder: demo_model - 데모 시연에 필요한 stl 출력물 파일이 있습니다.
folder: forntend - 화면 렌더링에 필요한 웹 문서가 있습니다.
build_job - STL모델이 업로드되면 cli toolpath로 변환 작업을 수행하기 위한 Tasker입니다.
cli_toolpath - cli path를 작성하기 위한 methods 입니다.
fipy_dt - 열 해석 모델
pre_lt_demo - 시연 용 LT-DT
pre_lt_dt - 실제 동작하는 LT-DT
process - 장비 config 
pybullet_dt - 장비 및 출력 물리 모델
stl_slicer - 모델을 슬라이싱 해서 변환 작업 할 수 있게 해줍니다.
test.~ - 테스팅 파일들
