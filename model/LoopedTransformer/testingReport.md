결론
| 항목      | 관찰                             |

| Width   | 대체로 실제값을 따라감. 다만 전반적으로 과대예측    |
| Depth   | 오차가 상당히 큼. 특히 일부 샘플에서 심각한 과대예측 |
| Area    | width/depth 오차의 영향으로 큰 오차 발생   |
| 전체적인 방향 | 단순히 랜덤하게 예측하는 것은 아님            |
| 가장 큰 문제 | **Depth prediction**           |

Rosenthal 모델 자체가 Depth는 단순하게 모델링하기 때문에 예측 성능이 나쁠 수 밖에 없다고 생각이 든다.
D ≈ W/2 라는 식을 쓰는데, Width 그러니까 열 전도에 대해서는 모델링이 좋지만 나머지는... 
그래서 수정이 필요할 것 같다.

전체 melt-pool geometry의 ground-truth physics model로는 적절하지 않고.. 저차 열전도에서 적절하다.


### Step 4 : 물리적 관계 정의 및 모델링 수정
일단 Depth에 대해 열전도를 모델링하는 것을 제거.. 관계만 파악하도록 변경

Linear Energy Density 추가
   E_L = P_laser / v_scan [J/mm]
   기존 P_laser, v_scan, d_laser, t_powder는 그대로 유지
즉 입력이 4 → 5 features

Rosenthal Physics Evaluator 수정
   기존의 D = W/2 제거
   Rosenthal은 W의 열적 스케일만 제약
Depth는 완전히 데이터 기반으로 학습 (수식 모델링하기가 너무 어려워서 어쩔 수 없었음..ㅜ)

Area는 $$ A \approx \frac{\pi}{4}WD $$ 의 기하학적 일관성만 검사

따라서 현재 데이터의 넓은 D/W 분포를 억지로 제한하지 않음. (데이터 flow대로 학습)
